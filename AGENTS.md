# AGENTS.md

Guidance for coding agents working in this repository. See `README.md` for the project story and roadmap; this file focuses on how the tree is organized, what the file formats are, and how to work with them.

## What this repo is

A fan preservation/remaster of **Piposh 3D** (released 2003), a game built on **3D GameStudio A5 (Acknex 5)**. The repo is the *installed game directory itself*, versioned in git: patched engine executables, scripts, and assets, plus a `tools/` pipeline layered on top. It is not a conventional source-code project; there is no build system, compiler, or test suite.

Two distinct environments:

- **Game runtime: Windows only.** The `.exe` modules, `.bat` launchers, and dgVoodoo wrapper only run on Windows (or a VM). They cannot be executed on macOS.
- **Asset tooling: cross-platform Python.** Everything in `tools/*.py` runs anywhere with Python + Pillow (a `.venv/` exists at the repo root). The Real-ESRGAN upscaler binary (`tools/realesrgan/`) is a Windows executable.

## How the game runs (launcher contract)

The game is ~50 separate A5 engine modules (`<Name>.exe` + matching `<Name>.wdl` in the repo root), one per scene/minigame, chained together. The contract, reverse-engineered from the original Director launcher and `IO.wdl`:

1. Boot module is always `Start.exe`.
2. A module hands off by writing the next module's exe name to `Run.txt` and bumping `Prefs/Date.txt` (see `Run()` in `IO.wdl`).
3. A module requests full quit by writing `0` to `Prefs/Flag.txt` (see `DoExit` in `IO.wdl`).

`Launch.bat` implements this loop and starts every module with `-d l1 -NX 512` (enlarged NEXUS heap). Two rules that matter when editing launchers:

- Never launch via the legacy `Piposh3D.exe` (Macromedia Director loader): it cannot pass engine flags like `-NX`.
- Always invoke `Start.exe` by **full path** in batch files; a bare `start.exe` is swallowed by cmd's `START` builtin and the `-NX` args are lost ("Nexus too small").

Entry points: `Go.bat` (splash + `Launch.bat`), `Launch.bat` (the real loop), `TestTown.bat` (launch the Town level directly with `-diag` for quick visual testing; `-diag` makes the engine write `acklog.txt`).

## File formats

| Extension | Format | Editable? |
|---|---|---|
| `.wdl` | **World Definition Language**: the A5 engine's C-like scripting language, plain text. Root-level `<Name>.wdl` is a module's main script; shared libraries live in `WDL/` (notably `IO.wdl`, duplicated at root, which holds the module-handoff logic). | Yes. The module exes are checksum-cracked, so edited scripts are accepted by the engine. |
| `.exe` (552K, root) | A5 engine binary, one per module, all identical engines differing only by which `.wdl` they load (matched by filename). Binary-patched: nexus 40→512 MB, INI override disabled, LARGEADDRESSAWARE, script/self-checksum defeated. `tools/patch_nexus.ps1` targets exactly the 565248-byte originals. | Only via the documented patch scripts. |
| `.mdl` / `.MDL` | 3D model binaries in **MDL3 / MDL5 / IDPO** (Quake1-style) variants: mesh, animation frames, and embedded skin textures (8-bit paletted or RGB565). `tools/mdl_tool.py` parses all three. A few terrain meshes are MDL2/MDL4 and are not supported by the tool. | Via the skin pipeline (below). Mesh/animation editing has no tooling here. |
| `.wmb` | Compiled A5 world/level geometry (BSP-like, with baked textures). No tooling in this repo; level textures are still stock in 0.0.1. | No (treat as opaque binaries). |
| `.pcx` / `.bmp` | 2D UI graphics and overlays in `GFX/`, referenced by the scripts. `GFX/palette.pcx` is the game's 256-color palette (also exported as `tools/game_palette.raw`) used to decode 8-bit skins. | Yes, standard image formats. |
| `.wav` / `.avi` / `.mp3` | Audio in `SFX/`, cutscene videos in `MOV/`. `Mp3AdvDll.dll` is the engine's MP3 plugin. | Standard media files. |
| `.wdf` / `.mdf` | `acknex.wdf` / `acknex.mdf`: engine window definition and resource data files required at runtime. | No. |
| `.dxr` | `russki.dxr`: Macromedia Director movie, part of the legacy launcher. Obsolete for the remaster. | No. |
| `dgVoodoo.conf` + `DDraw.dll` / `D3DImm.dll` | **dgVoodoo2** wrapper translating DirectDraw/D3D7 to modern GPUs; the conf holds supersampling/MSAA/filtering settings. Game stays at 640×480 internally. | Conf is plain text, safe to tune. |

Runtime state files (`Run.txt`, `Game.*`, `Save*.SAV`, `Flags.dat`, `acklog.txt`, etc.) are generated by playing and are gitignored; never commit them. `Prefs/` (`Date.txt`, `Flag.txt`, `Version.txt`) is the launcher handshake state and *is* tracked.

## Directory layout

```
<root>/*.exe + *.wdl      Game modules (patched engine + its script), 1:1 by name
Go.bat / Launch.bat       Remaster entry points; TestTown.bat = quick visual test
WDL/                      Shared/library scripts (IO.wdl, Cards.wdl, DIalog.wdl, ...)
WMB/                      Compiled levels
MDL/                      Live 3D models (many with 2x-upscaled skins re-embedded)
GFX/                      2D art (PCX/BMP) + palette.pcx
SFX/  MOV/                Audio and cutscene video
Prefs/                    Launcher handshake files (tracked)
skins_editable/<Model>/   Extracted skinN.png per model + _meta.json (the editing surface)
tools/                    Python MDL pipeline, upscale batches, nexus patchers, Real-ESRGAN
_backup_mdl/              Pristine original .MDL files
_backup_wdl/              Pristine original scripts
_backup_exe/              Original engines (checksum-cracked, pre-nexus snapshots in _backup_exe_pre_nexus/)
DOC/                      Original game docs (Help.doc, Solve.doc)
```

## Common commands

Skin/texture pipeline (import always rebuilds from the pristine `_backup_mdl/` copy and re-encodes to RGB565; UVs are rescaled automatically if your PNGs are larger than the originals; all PNGs in a model folder must share one size):

```
python tools/mdl_tool.py info    MDL/Piposh.MDL                    # inspect format/skins
python tools/mdl_tool.py extract MDL/Piposh.MDL skins_editable/Piposh
python tools/mdl_tool.py import  MDL/Piposh.MDL skins_editable/Piposh
tools\extract-skins.bat Piposh                                     # Windows wrappers
tools\import-skins.bat  Piposh
tools\upscale-skins.bat Piposh                                     # Real-ESRGAN 4x -> resized to safe 2x
python tools/batch_upscale_all.py                                  # batch 2x, all models
python tools/batch_reprocess_safe.py                               # UV-island-safe re-run (fixes AI bleed)
```

Engine patching (Windows): `tools\patch_nexus.bat` / `tools\patch_nexus.ps1` re-applies the nexus/LAA patches to any 565248-byte module exe.

## Conventions and gotchas

- **Back up before modifying originals.** The `_backup_*` trees are the restore path (copy back over `MDL/`, root `*.wdl`, or root `*.exe`). Don't touch them except to add a pristine copy of a file being modified for the first time; `extract-skins.bat` does this automatically for models.
- The root `IO.wdl` and `WDL/IO.wdl` both exist; the root copy is what modules load. Keep handoff logic changes consistent.
- Filename case is inconsistent (`.MDL`/`.mdl`, `.WMB`/`.wmb`); this ships to case-insensitive Windows filesystems, so preserve existing names rather than normalizing.
- Scene flow lives in each module's `.wdl` (which module it launches next via `Run()`), so "gameplay" changes are script edits, not code builds.
- Version 0.0.1 scope: models/skins are remastered, `WMB/` level textures and most `GFX/` are still stock, widescreen and the mode-select launcher are future roadmap items (see README).
